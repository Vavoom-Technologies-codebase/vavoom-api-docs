# Vavoom API Reference

Static API reference for integrators, hosted via GitHub Pages.

## View it live

https://vavoom-technologies-codebase.github.io/vavoom-api-docs/

## Download

Clone the repo:

```
git clone https://github.com/Vavoom-Technologies-codebase/vavoom-api-docs.git
```

Or grab just the page: open the repo, click `index.html`, then "Download raw file."

## Run it locally

Single self-contained file, no build step. Either:

- Open `index.html` directly in a browser, or
- Serve it: `python3 -m http.server 8000` from this folder, then visit `http://localhost:8000`

## Update the docs

Edit `index.html` directly, commit, and push to `main`. GitHub Pages redeploys automatically within a minute or two.

Includes a light/dark theme toggle using Vavoom's brand colors (`#0F1319` / `#CFFF2F`) in dark mode.
